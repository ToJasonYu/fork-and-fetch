# 🍴 Fork & Fetch

**Turn your ingredients into inspiration.** Fork & Fetch is an AI-powered culinary assistant that analyzes photos of your fridge or pantry and generates custom recipes instantly. Built with Next.js, TypeScript, Tailwind CSS, Google Gemini.

![Project Preview](https://via.placeholder.com/800x400?text=App+Screenshot+Here) 
## Features

- ** Visual Ingredient Analysis:** Upload a photo of your fridge, and the AI identifies ingredients automatically.
- ** Smart Constraints:** Filter recipes by meal type (Breakfast, Dinner), cooking time, and dietary restrictions.
- ** Responsive UI:** Beautiful, mobile-friendly interface built with Tailwind CSS.
